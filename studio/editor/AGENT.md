# Cutlab (Nick Editor) — как Claude работает с проектом

- Проект: `projects/<id>/project.json` (дорожки и клипы), `words.json` (слова по частям), `review.json` (правки).
- Менять проект — только операциями: `python3 studio/editor/cli.py op '<json>'` или удобными командами (`cut`). Прямая правка файла допустима, если сервер выключен; после — `cli.py validate`.
- Ждать «Исправить»: запустить в фоне `python3 studio/editor/cli.py wait-signal --project ep01` (Bash, run_in_background). Когда процесс завершится с «СИГНАЛ» — работать; потом снова запустить ожидание. Если есть незакрытая пачка (нажали «Исправить», пока ожидание не шло), `wait-signal` завершается сразу — значит, сначала её.
- Порядок по пачке: `cli.py inbox` → для каждой правки `status <id> working` → изменения → `reply <id> "что сделал" --done` (или `--question "что уточнить"`) → `notify <batch> --title "Готово N из N" --item "сек|клип|что сделал"` → `batch-done <batch>` (статус внизу снова «Claude следит»). `reply --done` без `status working` тоже принимается.
- Higgsfield: генерировать только если в правке `разрешено: да`; иначе спросить в чате с числом и ценой.
- Сгенерированное в монтаж **не ставить** — предлагать вариантами: файлы сохранить в `assets/shots/<кадр>/`, затем `cli.py propose <клип> <файл…> [--comment <id правки>] [--note "коротко про вариант" …]` (без `--comment` — карточка «Claude предлагает»). Пользователь выбирает «Поставить» в «Правках»; ответ «ни один не подходит» вернётся правкой в следующей пачке. В пачке после propose — `notify` можно не слать (propose сам шлёт «N вариантов — выбрать»), `batch-done` — как обычно.
- Время: `m:ss.s` или секунды. Склейка на слово: `cli.py cut <клип> --word zero` (упреждение 0,12 с; слово ищется после начала предыдущего клипа, `--nth N` — какое по счёту).
- Задачи дубляжа (`■ задача … dub`, языки в `params.langs`): спецификация `docs/superpowers/specs/2026-09-27-nick-editor-stage2-dub.md`. По каждому языку:
  1. `python3 studio/editor/dub.py plan --project ep01 --lang es` → список «кадр | бюджет | EN»; перевести **сам** (разговорно, коротко, в бюджет; числа с точкой — словами; бренды и имена как есть) → `projects/<id>/dubs/<lang>/text.json` `{кадр: текст}`.
  2. `dub.py blocks …` → блоки и цена. Если задача `разрешено: да` — озвучить: `generate_audio_batch` (по 12), `model: text2speech_v2`, `variant: elevenlabs`, `voice_type: preset`, `voice_id: 27c04473-84a9-4b60-a41f-c8e8458bd4f1`, prompt = текст блока; результат скачать в `dubs/<lang>/tts/<блок>.mp3`. Без разрешения — спросить в чате число × цену.
  3. `dub.py build …` → `dubs/<lang>/<id>_<lang>.mp3`. Код 1 = есть переполнения: сократить перевод этих блоков, переозвучить только их, собрать снова.
  4. Перевести название и описание ролика → `dubs/<lang>/meta.txt`; `cli.py job <id> done --note "ES, DE готовы"` и `notify - --title "Дубляж готов: ES, DE" --item "0|H1.1|дорожки в «Дубляж» → В Finder"`.
  Черновик CapCut только читается (`settings.capcut_draft`); подложка собирается один раз в `dubs/_bed/`.
- Рендер проекта в MP4 (этап 3): `python3 studio/editor/render_mp4.py --project <id> [--from 0 --to 80] [--jobs 8] [--out export/<id>/<id>_cut.mp4]` — кэш сегментов в `export/<id>/render_cache/` (повтор без изменений ~1 мин), ход — `export/<id>/RENDER_PROGRESS.md`, для просмотра пользователю — копия 720p. Черновая автосборка ep02 (материалы в кадры, подкадры ~4 с, анимации Ника, финальный блок): `studio/editor/autofill_ep02.py [--dry]`; голос глав: `studio/editor/assemble_ep02_voice.py`.
